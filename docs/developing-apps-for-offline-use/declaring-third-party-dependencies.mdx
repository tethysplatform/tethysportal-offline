# Declaring Third Party Dependencies

Typically in a Tethys app, you might declare third party javascript dependencies in your templates like the following:

```django
{% block scripts %}
  {{ block.super }}
  <script src="{% static 'my_app/js/main.js' %}" type="text/javascript"></script>
  <script src="https://cdn.jsdelivr.net/npm/jszip@3.7.1/dist/jszip.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/file-saver@2.0.5/dist/FileSaver.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/bootstrap@4.6.2/dist/js/bootstrap.bundle.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/papaparse@5.4.1/papaparse.min.js"></script>
{% endblock %}
```

When your apps use script tags like these, they reach out to a CDN in order to download the specified dependencies.
In an offline air-gapped environment, these requests will fail. In order to use dependencies like these you must declare
them in your app's `install.yml` file under the `requirements.npm` section.

The example below shows what an `install.yml` file might look like for the dependencies shown above:

```yml
# This file should be committed to your app code.
version: 1.1
# This should be greater or equal to your tethys-platform in your environment
tethys_version: ">=4.0.0"
# This should match the app - package name in your setup.py
name: my_app

requirements:
  # Putting in a skip true param will skip the entire section. Ignoring the option will assume it be set to False
  skip: false
  conda:
    channels:
      - conda-forge
      - nodefaults
    packages:

  pip:

# highlight-start
  npm:
    jszip: "3.7.1"
    file-saver: "2.0.5"
    bootstrap: "4.6.2"
    papaparse: "5.4.1"
# highlight-end

post:
```



`<link>` tags that specify a dependency CDN like the one below must also be added to `install.yml`:

```django
{% block styles %}
  {{ block.super }}
  <link href="{% static 'my_app/css/loone_map_view.css' %}" rel="stylesheet"/>
<!-- highlight-start -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@4.6.2/dist/css/bootstrap.min.css" rel="stylesheet">
<!-- highlight-end -->
{% endblock %}
```

Now that the dependencies are added to your app's `install.yml` file, Tethys will install these packages
when your app is installed, and serve them as static dependencies to your app. We must now update our
templates to retrieve these dependencies from the correct location. The [Template Tags](./template-tags)
section of this documentation shows you how to do this.
